# Exercise 2: Setting up Azure Migrate for App Migration

### Estimated Duration: 15 minutes

## Overview

Azure Migrate provides a centralized hub to assess and migrate on-premises servers, infrastructure, applications, and data to Azure. It offers a single portal from which to start, run, and track your migration, along with a range of assessment and migration tools that you will use during this lab.

## Objectives

You will be able to complete the following tasks:

- Task 1: Setting up Azure Migrate for App Migration

## Task 1: Setting up Azure Migrate for App Migration

In this task, you will configure Azure Migrate to assess the readiness of the application and database for migration to Azure services.

1. From the Windows search bar, search for **Default apps (1)** and select **Default apps (2)** from the results.

   ![](media/dfltapp.png)
   
2. On the **Default apps** blade, click **Microsoft Edge (1)**, then select **Set as Default** to make Microsoft Edge the default browser.

    ![](media/dflt2-1.png)

    ![](media/dflt2.png)
   
3. Open the **Azure portal** in the edge browser and sign in. When prompted, use the credentials below to complete the sign-in.

    * Email/Username: <inject key="AzureAdUserEmail"></inject>
    * Temporary Access Pass: <inject key="AzureAdUserPassword"></inject>

      ![](media/GS1.png)

4. Select your **hands-on-lab-<inject key="DeploymentID" enableCopy="false"/>** resource group. 

    ![](media/slctrg.png)

5. Select **+ Create** within the resource group to add a new resource.
    
    ![](media/clickcreate.png)

6. Type **Azure Migrate** into the search box and select it from the results.

    ![](media/azmig.png)

7. Select **Create (1)** and click on **Azure Migrate (2)** to continue.

    ![](media/createazmig.png)

    >**Note:** If you land on the new version of Azure Migrate, you can create a project directly from the **Get Started** page. Click **Create project** and then follow the same steps.
    
8. Select **All projects** and click **(+) Create project** to create a new project.

   ![](media/allproj.png)

9. Type **partsunlimitedweb<inject key="DeploymentID" enableCopy="false"/> (1)** as the project name. Select **Create (2)** to continue. 

    ![](media/partsun.png)

> **Note:** The assessment and migration work in this lab is performed by two tools that are already installed on the web and database servers — the **App Service Migration Assistant** (Exercises 1 and 3) and the **Microsoft Data Migration Assistant** (Exercise 4). This Azure Migrate project is the destination those tools upload their assessment results to, so create it now and continue with the pre-installed tools.
